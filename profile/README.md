## Sinchonthon: 멋쟁이사자처럼 대학 소속 신촌권역 대학교 연합 해커톤

**신촌톤**은 전국 최대 규모 IT 창업 동아리 ‘멋쟁이사자처럼 대학’ 소속 신촌권역 5개 대학교(명지대, 서강대, 연세대, 이화여대, 홍익대)의 연합 해커톤입니다. 혁신적인 창업 생태계 조성을 위해, 신촌권역 대학교 학생의 창업 역량 강화와 네트워킹을 도모합니다.

14기 신촌 아기사자 여러분께서 그동안 갈고닦은 실력을 발휘하는 무대가 될 수 있기를 바랍니다.

여름방학의 마지막, 빛나는 아이디어와 열정을 보여주세요!<br />
